# ФотоТочка — стоковый маркетплейс. От гипотезы до продакшна

![Django](https://img.shields.io/badge/django-5-green)
![Vue](https://img.shields.io/badge/vue-3-42b883)
![AI](https://img.shields.io/badge/AI-агенты-8A2BE2)

Django 5 + Vue 3, полный цикл. Диплом как повод — не результат. Гипотеза была: «Можно ли построить production-grade маркетплейс в одиночку, используя AI-агентов на каждом этапе — от прототипирования до деплоя?»

**Ответ:** да. Figma → Nginx за 2 недели. Docker, E2E, CI — всё через AI-агентов. Оптимизация изображений, балансировка нагрузки и ценообразование — спроектированы с помощью LLM, реализованы вручную там, где агент не вывозит.

Продакшн-эффект: Playwright E2E отлавливает регрессии до деплоя, автоматический скрипт разворачивает на VDS одной командой, AI дорисовывает визуал. Качество — Pytest + Visual Regression, без ручного тестирования.

---

## Зачем это

Не «диплом». Проверка гипотезы: может ли один разработчик с AI-агентами выдать продукт, который не стыдно показать заказчику?

Оказалось — может. Но не на всём: AI отлично пишет рутину, плохо проектирует архитектуру на стыке сервисов. Этот проект — граница: где AI ускоряет, а где пока только человек.

**Главный инсайт:** AI-агенты заменяют исполнителя, но не архитектора. Пока.
